# Flappy Game (Pygame)

A 2D arcade physics game recreated in Python using the Pygame library.

## Features

- **Physics Simulation:** Delta-time gravity calculation, velocity clamping, and jump impulses.
- **Collision Detection:** Pixel-accurate bounding box checks between player sprite and pipe obstacles.
- **Audio & Scoring:** Procedural score tracking, high score persistence, and sound effects.

## Tech Stack

- Python 3.8+
- Pygame (`pygame`)

## Play

```bash
pip install pygame
python main.py
```
